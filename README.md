# willow-app
A meditation app to chat with AI Greek Philosophers

## Development

```
npm install
npm run dev
```

## Gemini API key

Willow calls the Gemini API directly from the browser. Click the key icon in
the sidebar to paste your own Gemini API key (get one from
[Google AI Studio](https://aistudio.google.com/app/apikey)). The key is
stored only in `localStorage` in your browser and is never sent anywhere
except Google's API.

## Build

```
npm run build
npm run preview
```
